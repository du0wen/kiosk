Capabilities

Built for teams sharing AI artifacts safely

Everything needed to move generated dashboards, reports, and prototypes out of local chats without exposing your domain to XSS or data exfiltration.

🛡️

Double-Origin & Zero-Network CSP

Console cookies are bound strictly to APP_ORIGIN via __Host- cookies. Served pages run on an isolated SERVE_ORIGIN inside sandboxed iframes blocking all outbound network calls.

⚡

Native Rust CLI

Single-binary CLI for macOS, Linux, and Windows with OIDC browser login, same-URL updates, org template lookup, and PDF/PNG export. Zero runtime dependencies.

🤖

Native MCP 2.0 Server

Connect Claude Desktop, Claude Code, Cursor, or Codex directly to POST /mcp with scoped API tokens for publishing, listing, visibility switching, and cleanup.

🎨

Org Templates & Full-Page Watermarks

Manage versioned HTML style templates by category, apply organization branding, and enforce tamper-resistant diagonal viewer watermarks on both web and exports.

📄

Air-Gapped Export Microservice

Convert pages to Markdown or HTML locally, or render pixel-accurate PDF, PNG, and JPEG through an isolated Chromium container with external Internet disabled.

🧭

Web Setup Wizard & Self-Hosting

Spin up with Docker Compose or Vercel + Neon. Built-in first-run /setup wizard configures Postgres, local or S3/R2 storage, and invite-only policies with zero hand-editing.

Security Architecture

Defense-in-depth isolation by default

Arbitrary AI-generated HTML never shares an origin, cookie jar, or network surface with your workspace console.

APP_ORIGIN · app.kioskai.dev

Console, API & Branded Shell

  • Next.js App Router console, OAuth/OIDC, and organization RBAC
  • __Host- session cookies strictly locked to APP_ORIGIN
  • REST v1 API, stateless MCP server (/mcp), and /v/:id branded wrapper
  • Mints short-lived HMAC serve tokens for org-private pages
→
Sandboxed iframe + HMAC Token
SERVE_ORIGIN · isolated domain

Stateless Zero-Network Serving

  • Separate registrable domain with zero cookies and zero storage
  • Strict CSP: default-src 'none'; connect-src 'none'; form-action 'none'
  • Verifies signed token gate before returning org-private HTML
  • Completely isolated from console credentials and internal APIs
